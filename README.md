This is the official implementation of the paper:  
**"Hyperspectral and Multispectral Image Fusion via Neural Tensor Decomposition With Factor Alignment"**.

---

## 📖 Introduction

This repository contains the demo code for our proposed HSI-MSI fusion method. By utilizing **Neural Tensor Decomposition (NTD)**, the framework optimizes tensor factors through neural networks, effectively preserving both high-resolution spatial details and rich spectral information.

---

## 🛠 Requirements

The code is developed and tested under the following environments:

* **Operating System**: Windows/Linux/macOS
* **Python**: 3.11.0
* **Core Libraries**:
    * `torch == 1.12.1`
    * `scipy == 1.15.2`
    * `numpy == 1.26.4`
